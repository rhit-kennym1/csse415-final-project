# Phishing Website Detection

CSSE415 Final Project - Ervin Perkowski, Mark J. Kenny, Sanil Maheshwari

## Notebooks

| File | Description |
|---|---|
| `Baseline.ipynb` | Majority class baseline, always predicts phishing (55.7% accuracy) |
| `LogReg.ipynb` | Logistic Regression with feature engineering, Lasso, and Ridge variants |
| `DTClassifier.ipynb` | Decision Tree with hyperparameter tuning, PCA, and feature engineering |
| `LinClass.ipynb` | Ridge Classifier with tuning, PCA, and feature engineering |
| `SimpleKNN.ipynb` | k-Nearest Neighbors baseline and tuned variants |
| `RandForest.ipynb` | Random Forest with tuning, feature importance, and pairwise interaction features |
| `GradientBoosting.ipynb` | Gradient Boosting with tuning, feature engineering, and PCA, best overall model |
| `SVM.ipynb` | SVM (RBF kernel) with tuning and feature engineering via manual cross-validation |
| `415XGBoost.ipynb` | XGBoost with same feature engineering and PCA variants as Gradient Boosting |
| `415DataAnalysis.ipynb` | Exploratory analysis of datasets 2–6 from the Kaggle source |
| `DS2_Exploration.ipynb` | Decision Tree and Ridge Classifier applied to Dataset 2 (111 features, 88K samples) |
| `Mark.ipynb` | Scratch notebook |
